🔐 Politique de confidentialité

La présente politique concerne le bot Discord Virtual Vibes (« VVs Bot »).

Dernière mise à jour : 21 août 2026

1. Informations traitées

Discord

Pour fonctionner, le bot peut traiter des identifiants techniques Discord, notamment l'identifiant de l'utilisateur ayant effectué une action et l'identifiant du serveur concerné.

Le bot utilise également les informations nécessaires à ses fonctionnalités de modération, de gestion et de configuration des serveurs.

VRChat

Lorsque les fonctionnalités VRChat sont utilisées, le bot peut traiter le nom d'utilisateur VRChat, l'identifiant du compte et certaines informations fournies par l'API VRChat.

Modération

Les fonctionnalités de modération peuvent enregistrer des informations telles que la cible d'une action, le motif, la date, le modérateur à l'origine de l'action et les informations nécessaires à l'historique de modération.

2. Connexion à VRChat

La commande /login permet à un utilisateur autorisé de connecter un compte VRChat au bot. Le fonctionnement actuel prévoit également une étape 2FA lorsque VRChat la demande.

Une session VRChat et les informations techniques nécessaires à son maintien peuvent être conservées afin de permettre au bot de poursuivre ses fonctionnalités de surveillance et de gestion.

Important : ne transmettez jamais vos identifiants VRChat au bot si vous ne souhaitez pas lui permettre d'utiliser les fonctionnalités nécessitant cette connexion. Le bot doit être utilisé uniquement par des personnes autorisées à connecter le compte concerné.

3. Pourquoi ces données sont-elles utilisées ?

  • Associer une action à l'utilisateur Discord qui l'a effectuée.
  • Associer un compte VRChat à un serveur ou à une configuration.
  • Permettre la surveillance et la récupération d'informations depuis VRChat.
  • Gérer les actions de modération et leur historique.
  • Relayer certaines informations VRChat vers les salons Discord configurés.
  • Maintenir les fonctionnalités et la configuration du bot.

4. Publication des données

Le bot peut publier certaines informations de modération sur un dépôt GitHub utilisé pour le site de consultation des bannissements.

Selon les données enregistrées par le système, cette publication peut notamment contenir un nom ou identifiant VRChat, une raison, une date, un modérateur, un avatar et des statistiques liées à la modération.

À retenir : les informations publiées sur une page GitHub Pages publique peuvent être accessibles à toute personne disposant du lien ou trouvant la page.

5. Services tiers

Virtual Vibes fonctionne avec plusieurs services externes nécessaires à certaines fonctionnalités :

  • Discord — plateforme sur laquelle le bot fonctionne.
  • VRChat — source des fonctionnalités et informations VRChat utilisées par le bot.
  • GitHub / GitHub Pages — hébergement du site et, selon la configuration, publication de certaines informations de modération.

Ces services disposent de leurs propres règles et politiques de confidentialité.

6. Conservation et suppression

Les données sont conservées aussi longtemps que nécessaire au fonctionnement des fonctionnalités auxquelles elles sont associées, sous réserve des capacités techniques du bot et de sa base de données.

Lorsqu'une fonction de déconnexion ou de suppression prévue par le bot est utilisée, les informations associées peuvent être retirées de la configuration correspondante.

La suppression d'une information déjà publiée sur un service tiers peut nécessiter une suppression séparée sur ce service.

7. Sécurité

Des mesures techniques sont utilisées pour limiter l'accès aux données et aux fonctionnalités sensibles. Cependant, aucun système informatique ne peut garantir une sécurité absolue.

Les personnes administrant le bot doivent notamment protéger les secrets, tokens, identifiants et fichiers de configuration utilisés par le bot.

8. Droits et demandes

Pour toute demande concernant des données associées à Virtual Vibes, leur utilisation ou leur suppression, contactez l'équipe responsable du bot via ses moyens de contact officiels.

Pour faciliter une demande, indiquez si possible votre identifiant Discord ou VRChat et expliquez précisément les informations concernées.

9. Modifications

Cette politique peut être modifiée lorsque le fonctionnement du bot, les services utilisés ou les pratiques de traitement des données évoluent.

La date de dernière mise à jour affichée en haut de la page permet d'identifier la version actuellement publiée.

10. Contact

Pour toute question concernant cette politique ou les données traitées par Virtual Vibes, contactez l'équipe du projet via les moyens de contact officiels de Virtual Vibes.
